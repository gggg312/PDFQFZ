# Licensing status

The upstream [`flytkgl/PDFQFZ`](https://github.com/flytkgl/PDFQFZ) repository does not currently contain a root `LICENSE` file, and GitHub does not identify a project-wide license for it. For that reason, this fork does not add an MIT license or claim that the complete derived source tree is MIT-licensed.

The upstream author has publicly allowed modifications while requesting attribution in [Issue #107](https://github.com/flytkgl/PDFQFZ/issues/107). The upstream repository link and original author information are retained.

Third-party components keep their own licenses. In particular, iTextSharp is licensed under AGPL-3.0 (or a separate commercial license), while the PDFium-related packages and build tooling use their respective Apache, BSD-style, and MIT terms. The applicable license texts retained with this repository are under [`LICENSES/`](./LICENSES/); component details are listed in [`THIRD-PARTY-NOTICES.md`](./THIRD-PARTY-NOTICES.md).

This file documents the repository's current licensing evidence. It is not a new license grant for upstream code or for the complete combined work.
