# PDFQFZ GG优化版

> PDF 盖页面章与骑缝章工具（GG 优化版），基于 [flytkgl/PDFQFZ](https://github.com/flytkgl/PDFQFZ) `v1.33` 源码优化。

![软件封面](1.2封面.png)

## 前言

日常工作中我经常使用本工具，其中使用最频繁的就是页面盖章功能。长期使用下来，积累了不少实际痛点，因此基于个人使用场景做了针对性优化：

- **重构页面盖章交互逻辑**：支持单击盖章、按指定范围批量盖章、双击删除印章，操作更直观高效；
- **优化预览体验**：原版 PDF 预览区域偏小，界面也无法放大，查看文档、定位印章位置较为吃力；现程序窗口默认尺寸已调大，支持全屏查看，预览界面新增了缩放功能；
- **调整界面布局**：重新排布整体 UI，并新增操作提示区域，辅助用户上手使用。

## 与原作者的关系

本项目基于 `flytkgl/PDFQFZ` 的 `v1.33` 源码进行了界面、功能优化，十分感谢原作者开源并持续维护本工具。本仓库保留上游项目链接和原作者信息，与原仓库相关的问题和更新仍应参考上游仓库。

## 下载与安装

- 最新版本：**V1.2 GG优化版**，前往 [Releases](https://github.com/gggg312/PDFQFZ/releases) 下载。
- 单个 EXE 文件，支持 Windows 10/11（x86/x64），下载后直接运行即可。
- 首次运行后，会在 EXE 同目录生成配置文件 `yz.log`、`config.ini`，建议将 EXE 单独放在一个文件夹，发送快捷方式到桌面使用，以免误删或误改配置文件。

## 快速上手

1. 选择文件模式或目录模式，导入 PDF。
2. 选择页面盖章方式：手动点击盖章或指定范围页盖章。
3. 导入印章图片，根据预览和提示设置位置、大小、旋转和不透明度。
4. 手动模式下单击页面添加印章；指定范围模式下先输入起止页码，再点击页面完成一批。
5. 检查预览中的印章，双击需要移除的印章。
6. 点击“盖章”一次性生成输出文件。

## 功能详解

### 1. 文件模式 / 目录模式

- 文件模式：选择或拖入单个/多个 PDF 文件处理；
- 目录模式：选择整个目录批量处理。

### 2. 盖章类型

- **页面盖章**
  - 手动点击盖章：单击页面添加一个印章，多次单击可添加多个；双击已有印章可删除；
  - 指定范围页盖章：输入起始页和结尾页，点击页面后会在范围内各页的相同位置各添加一个印章；需要多个印章时重复操作。
- **骑缝章**：不加骑缝章 / 加盖骑缝章 / 单页骑缝章 / 双页骑缝章 / 随意骑缝章。

### 3. 盖章模式

- **合并（盖章不可编辑）**：默认模式，盖章直接合入页面内容。注意：合并后文字不可编辑，且原数字签名会丢失；
- **叠加（盖章浮于页面）**：盖章以可编辑元素浮于页面上。

### 4. 数字签名

不使用数字签名 / 签名 / 密码。

### 5. 印章设置

印章尺寸（mm）、旋转（°）、旋转处理（旋转切边）、不透明度（%）、随机参数、去除白色背景（可设置容差）。

### 6. 骑缝章设置

骑缝章位置、位置（%）、骑缝章最大分割数。

### 7. 其他

PDF 密码。

### 8. 预览操作

- **翻页**：单页视图下鼠标滚轮翻页，或使用上一页/下一页按钮、输入页码回车跳转；
- **缩放**：`Ctrl+鼠标滚轮` 一次调整 10%，工具栏按钮一次调整 25%，支持 100%–300%（100% 为最小比例）；
- **拖拽**：放大查看时按住鼠标左键拖动页面，查看超出窗口的区域；
- **视图切换**：单页视图 / 放大视图；
- 单击页面添加印章，双击已有印章删除。

### 9. 输出文件与配置

- 输出文件沿用现有命名规则，并根据同一源文件已存在的输出文件自动使用 `V1`、`V2`、`V3` 等版本号，不覆盖旧结果，例如 `1.pdf` 输出为 `1_已盖章V1.pdf`；
- 首次启动默认：文件模式、不加骑缝章、不盖页面章、合并模式。

## 编译与依赖

- 主要项目为 .NET Framework 4.7.2 WinForms，可用 Visual Studio 2022 打开 `PDFQFZ.sln`；
- 测试项目使用 .NET 9 Windows 测试工程，当前自动测试 `65/65` 通过；
- 改用开源 PDFium 渲染（`PdfiumViewer.Updated 2.14.5`、`bblanchon.PDFium.Win32 153.0.8009`），x86/x64 原生组件均嵌入单 EXE；
