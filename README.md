# PDFQFZ V1.0 GG优化版

## 与原作者的关系

本项目基于 [flytkgl/PDFQFZ](https://github.com/flytkgl/PDFQFZ) 的 `v1.33` 源码进行了界面、功能优化。十分感谢原作者开源并持续维护这个工具。
本仓库保留上游项目链接和原有作者信息，与原仓库相关的问题和更新仍应参考上游仓库。

## 前言

日常工作中我经常使用本工具，最常使用页面盖章相关功能。在长期使用过程中，也积累了不少实际使用痛点，因此基于个人实际使用场景做了针对性优化：：

-重构优化原有页面盖章的整套交互逻辑；

-原版 PDF 预览区域尺寸偏小，查看文档、定位印章位置较为吃力，因此放大程序窗口与预览视图，提升预览可视效果；

-窗口放大后原版 UI 布局不再适配，重新调整整体界面排布；同时新增操作提示区域，降低上手成本；

## 本版改动大纲

1. 重新设计界面布局，放大软件窗口和 PDF 预览区域，方便查看和定位。
2. 页面盖章仅保留“手动点击盖章”和“指定范围页盖章”两种方式，默认支持多章连盖。
3. 支持同页、跨页连续添加多个印章，并可双击删除指定印章。
4. 新增指定范围批量盖章，支持页码输入、范围校验和指定位置批量生成。
5. 优化页码跳转、操作提示、白色背景去除和输出文件版本号。

## 详细改动说明

### 1. 页面盖章

- “手动点击盖章”：在右侧 PDF 预览中单击一次添加一个印章，多次单击可添加多个印章。
- “指定范围页盖章”：输入起始页和结尾页，跳转到范围内最后一页，下一次点击会在范围内各页的相同位置添加一个印章。需要再加一批时，重复点击该按钮。
- 切换页面时，已添加的印章位置保留；双击普通印章可删除单个印章，批量印章可选择删除当前页或整批。
- 保存时从原始 PDF 重新生成，不读取旧输出文件，避免重复叠加。

### 2. 界面和操作

- 默认窗口约为 `1500×900`，支持调整大小和最大化，PDF 预览会根据右侧可用空间自适应缩放。
- 文件模式、骑缝章、页面盖章和盖章模式改为分组可见的选项，右上角输入页码并按回车可跳转。
- 删除“多章连盖”按钮，页面单击默认始终为追加印章。
- 左下角保留系统提示文字区，右侧预览上方增加操作提示区，根据当前操作显示状态。
- “白色透明”改为“去除白色背景”，未勾选时禁用容差，勾选后可设置近白色范围。

### 3. 保存和输出

- 输出文件沿用现有命名规则，并根据同一源文件已存在的输出文件自动使用 `V1`、`V2`、`V3` 等版本号，不覆盖旧结果。
- 操作提示会显示原文件名和输出文件名，例如：`1.pdf` 输出为 `1_已盖章V1.pdf`。
- 默认首次启动为：文件模式、不加骑缝章、不盖页面章、叠加模式。

## 沿用原作者的内容

本版没有重写原作者的骑缝章核心处理逻辑，仍沿用原项目的骑缝章功能。左侧设置区的四类主体功能也继续沿用：

- 数字签名
- 印章设置
- 骑缝章设置
- 其他（包括 PDF 密码等）

为配合新界面，上述四类中的控件位置、标签文字、默认值和与新页面盖章模式的联动方式做了适配，因此“沿用”指的是主体功能和处理方式，不是界面形式完全不变。

## 使用方法

1. 选择文件模式或目录模式，导入 PDF。
2. 选择页面盖章方式：手动点击盖章或指定范围页盖章。
3. 导入印章图片，根据预览和提示设置位置、大小、旋转和不透明度。
4. 手动模式下单击页面添加印章；指定范围模式下先输入起止页码，再点击页面完成一批。
5. 检查预览中的印章，双击需要移除的印章。
6. 点击“盖章”一次性生成输出文件。
